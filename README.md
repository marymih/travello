# Travello

Landing page for a travel guide app, built as layout practice from the free "Travello" design by TemplatesJungle.

**Live demo:** https://marymih.github.io/travello/

**Status:** work in progress. All page sections are in place (header, hero, features, destination cards, reviews, highlights, pricing, info and footer). The page is desktop-only for now: mobile and tablet layouts are not done yet.

## What's inside

- Semantic HTML5 markup
- SCSS with variables and mixins, compiled to minified CSS
- CSS Grid and Flexbox layouts
- Small vanilla JavaScript: star ratings rendered from data attributes and a reviews slider

## Stack

HTML5, SCSS, JavaScript

## Run locally

No build step is needed to view the page: clone the repository and open `index.html` in a browser.

To change the styles, edit the files in `styles/` and compile `styles/style.scss` to `styles/css/style.min.css`, for example:

```bash
npx sass styles/style.scss styles/css/style.min.css --style=compressed
```
